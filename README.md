[Foxl](https://foxl.ai) is a personal AI agent for research, writing, and everyday work. This tap provides its macOS desktop app through Homebrew, using the same universal DMG published in Foxl's releases.

## Install

You need [Homebrew](https://brew.sh) and **macOS 13 Ventura or newer**. The universal app supports Apple silicon and Intel Macs.

```sh
brew install --cask foxl-ai/tap/foxl
```

The fully qualified cask name identifies both this tap and the Foxl cask. Homebrew can add the tap as part of that command.

If you prefer to add the tap explicitly:

```sh
brew tap foxl-ai/tap
brew install --cask foxl-ai/tap/foxl
```

Open **Foxl** from Applications, connect your chosen model, and bring a small task.

> “Help me turn this idea into a plan I can start today.”

## Keep Foxl current

Foxl updates itself in place. The cask declares `auto_updates true`, so ordinary Homebrew upgrades skip it.

To explicitly update through Homebrew:

```sh
brew update
brew upgrade --cask --greedy foxl-ai/tap/foxl
```

To inspect the cask and installed version:

```sh
brew info --cask foxl-ai/tap/foxl
brew list --cask --versions foxl
```

[Release history](https://github.com/foxl-ai/foxl/releases) · [Changelog](https://foxl.ai/changelog)

## Remove the app

```sh
brew uninstall --cask foxl
```

Homebrew's optional `--zap` cleanup also removes the paths listed in [Casks/foxl.rb](Casks/foxl.rb), including Foxl's local data. Review that list before choosing to remove your data.

## Designed to be inspectable

**A small installation surface.** One cask describes the app, its download, its operating-system requirement, and its cleanup paths.

**A specific release and digest.** The cask pins a Foxl release and SHA-256 checksum. Release automation reads the published release metadata and GitHub's asset digest before generating the update.

**Controlled publication.** The protected `main` branch uses a controlled publishing window for the `foxl-bot` GitHub App, and generated commits must be signed. Repository history shows the version and cask content that changed.

You can inspect the [cask](Casks/foxl.rb), [commit history](https://github.com/foxl-ai/homebrew-tap/commits/main/), and [published release assets](https://github.com/foxl-ai/foxl/releases/latest).

## About this repository

The cask and README are generated by Foxl's release automation. Changes need to be made in the generation source so the next release preserves them. Pull requests can propose changes; normal publication follows the bot's protected release path.

Foxl's application source is maintained separately. For the desktop app's terms, see the [Foxl license](https://github.com/foxl-ai/foxl/blob/main/LICENSE).
